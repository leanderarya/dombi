## Cara Cepat Cari File Relevan

Semua UI adalash React di `resources/js/pages/<role>/`, backend Laravel di `app/Http/Controllers/`.

### Role → Direktori halaman
| Role | Pages | Backend |
|------|-------|---------|
| Customer | `resources/js/pages/customer/` | `app/Http/Controllers/Customer/` |
| Outlet | `resources/js/pages/outlet/` | `app/Http/Controllers/Outlet/` |
| Owner | `resources/js/pages/owner/` | `app/Http/Controllers/Owner/Controller.php` |
| Courier | `resources/js/pages/courier/` | `app/Http/Controllers/Courier/` |
| Guest | `resources/js/pages/guest/`, `resources/js/pages/track.tsx` | `app/Http/Controllers/Guest/` |

### Route → Controller/Page
- Route list: `routes/web.php`
- Inertia page mapping: `resources/js/routes/*/index.ts` → `resources/js/pages/*/`

### Module Owner (sering bug)
`pages/owner/`: `analytics/`, `couriers/`, `customers/`, `deliveries/`, `exchange/`, `finance/`, `inventories/`, `orders/`, `outlets/`, `pricing/`, `product-categories/`, `restocks/`, `returns/`

### Bug umum (pola dari `docs/TESTING.md` Known Issues)
1. **Key mismatch** `product_variant_id` vs `product_id` frontend↔backend — UI kirim key lama, backend validasi beda. Cek payload form + `Request` class.
2. **Prop mismatch** Inertia — controller kirim `X`, UI baca `Y`. Cek `Inertia::render` di controller vs destructure di page.
3. **Route parameter mismatch** `{delivery_tier}` vs `$tier`. Cek `routes/web.php` + controller method signature.
4. **Field `courier_type` hilang** di request assign courier. Cek `AssignCourierRequest` + UI sheet.
5. **Stale stock / stale quote** — UI tidak re-fetch setelah data berubah. Cek `router.reload` / `router.visit`.
6. **Dialog/sheet tidak auto-close** setelah submit — missing `onSuccess` di `router.post`.
